# Linux C++ HTTP服务器

## 项目简介

个人服务器实践项目。参考开源WebServer设计思路，
使用C++实现Linux环境下的HTTP服务器，
学习并实践网络编程、协议解析、多线程协作及MySQL接入。

## 当前实现范围

- HTTP解析：基于有限状态机解析请求行、请求头和正文，
  实现GET、HEAD、PUT、POST、DELETE的基础处理。
- 并发架构：采用主从Reactor模型，主线程接收并分发连接，
  工作线程维护各自的epoll事件循环。
- I/O模式：实现epoll ET/LT触发模式切换。
- 数据访问：为部分请求实现对应SQL操作，
  使用连接池管理MySQL连接，并提供连接借用与归还机制。
- 异步日志：采用生产者—消费者模型，
  将日志写入交由独立日志线程处理。

## 模块划分

- HTTP_parse.cpp
  实现HTTP解析有限状态机，提供请求解析功能。

- database.cpp
  封装数据库连接管理及SQL执行功能。

- json_parse.cpp
  实现业务参数与JSON数据解析。

- thread_demo.cpp
  组织服务器启动、事件循环、连接分发及模块间调用。

## 实现边界

本项目为学习实践项目，HTTP解析和数据库操作仅覆盖
当前已实现的功能子集，不宣称完整HTTP协议兼容或生产级可用。
